KiriPanel —— 用 New 3DS 玩吉里吉里（KiriKiri）galgame
==================================================

上屏：Moonlight 串流的游戏画面。
下屏：原生显示台词、说话人、历史和选项，点一下就能前进、选择、自动、快进、
      快存快读、打开存读档和设置、回到标题。电脑上游戏自己的对话框可以自动隐藏，
      免得上屏重复显示一遍文字。

插件只调用游戏自己的函数，不模拟鼠标键盘；只往游戏目录里加文件，不改游戏自己的
任何文件，随时可以一键卸载。


一、需要什么
------------
  - New 3DS / New 3DS LL（旧 3DS 解码不动串流）
  - 电脑上装好 Sunshine（或 GeForce Experience 的串流），能被 Moonlight 连上
  - 本压缩包：KiriPanel.exe（电脑端）和 3DS 文件夹（3DS 端）
  - 3DS 和电脑在同一个局域网


二、安装
--------
1. 3DS 端
   - 自制系统用户：把 3DS\moonlight.3dsx 放到 SD 卡 /3ds/ 里，从 Homebrew Launcher 打开；
     或用 FBI 安装 3DS\moonlight.cia。
   - 第一次打开时和普通 Moonlight 一样，选择电脑、输入配对码。

2. 电脑端
   - 双击 KiriPanel.exe，会打开管理窗口。
   - 点「＋ 添加游戏」，选游戏所在的文件夹（有游戏 .exe 的那一层）；
     选放游戏的总文件夹也可以，会自动找出里面所有吉里吉里游戏。
   - 选中游戏，点「一键安装」。
   - 想先确认能不能用：点「检测兼容性」。它会用一个空的临时存档启动一次游戏，
     自动点过片头到标题画面，然后关掉游戏、恢复原样，大约一分钟。
     你的存档不会被碰到（经启动器启动、不认临时存档的游戏，会先备份 savedata，结束后原样恢复）。
   - Windows 防火墙第一次弹窗时，请允许 KiriPanel 访问「专用网络」。


三、每次玩
----------
  1. 打开 KiriPanel（保持窗口开着；关掉窗口，3DS 就收不到台词了）。
  2. 照常启动游戏（双击游戏，或在 KiriPanel 里点「启动游戏」）。
  3. 3DS 上打开 Moonlight，串流电脑桌面或游戏。下屏会自动变成台词面板。

  KiriPanel 窗口顶上会显示「3DS 已连接」和正在运行的游戏；「正在运行」卡片里能看到
  3DS 此刻看到的台词。


四、3DS 上的操作
----------------
  点下屏台词 / A ……… 前进（打字中先显示完整句）
  点选项 / ↑↓ + A …… 选择
  L ……………………… 历史（↑↓ 翻，B 回到最新）
  R ……………………… 快进        X …… 自动        Y …… 重播语音
  START / 「菜单」…… 设置、存档、读档、回到标题、直接操作游戏画面
  标题画面上 ………… 下屏直接显示「继续游戏 / 开始游戏 / 读档 / 设置」

  连不上电脑上的中继时，下屏会提示，点一下卡片就立刻重试一次
  （中继一直连不上时它自己会拉长重试间隔，免得影响串流）。

  游戏自己的存档、读档、设置画面是满屏鼠标界面：进入时下屏自动切换成「镜像」，
  在下屏直接点；回到正文后自动切回台词面板。HOME 菜单里也可以手动切换
  DIALOG（台词面板）/ MIRROR（镜像触屏）。

  「快读」和菜单里的「回到标题」要点两次确认（游戏自己的确认框会出现在电脑上，
  3DS 点不到，所以由面板来问）。回到标题时游戏会存一份进度，标题画面的
  「继续游戏」能回到这里。


五、支持哪些游戏
----------------
不是所有吉里吉里游戏都能用。KiriPanel 的「检测兼容性」会告诉你属于哪一档：

  完整支持     有专门的适配器：台词、选项、自动/快进、快存快读、游戏菜单、回到标题、
               隐藏电脑上的对话框都能用。
  基本支持     用通用 KAG3 适配器：台词和说话人的名字、[link] 选项、前进、自动、
               快进、回到标题、隐藏电脑上的对话框；标题菜单会以面板上的按钮出现；
               游戏的存档/读档/设置画面会照搬到下面的屏幕，直接点就行；游戏弹出
               确认框时面板会提示你到电脑上回答。
               KAG3 没有统一的快存，所以「快存/快读」用不了。
  需要适配器   插件能在游戏里运行，但还没有适配器认识它。可以在游戏运行时点
               「导出诊断报告」，用来编写新适配器。
  需经启动器   这个程序只是启动器，检测时请在「启动用」里选它，或直接正常启动游戏看是否连上。
  不支持       插件无法挂进这个游戏（游戏不加载任何插件、加了特殊的壳、
               或自带的 version.dll 和 mpr.dll 都已占用），原因会写在结果里。

实测过的游戏（2026-10）覆盖 KiriKiri Z 1.3.x 与 KiriKiri 2、32 位与 64 位引擎，
包括柚子社、Frontwing 等使用「KAG Ex」系统的吉里吉里Z游戏（完整支持），
标准 KAG3 游戏（基本支持），经汉化启动器启动的游戏，以及 64 位 krkr2 引擎。
具体哪些游戏能用到哪一档，以「检测兼容性」的结果为准。

已知的小差异：
  - 有的游戏标题菜单要鼠标悬停才出现，在 3DS 上用镜像模式点。
  - 有的游戏第一次启动停在语言选择画面，在电脑上点一下即可，之后不再出现。
  - 有些游戏第一次启动会问「是否启用在线补丁检测」，在电脑上回答一次即可。


六、字体（可选）
----------------
3DS 端已经内置了常用的简体、繁体、日文汉字和符号（约 1.2 万字）。遇到极少见的字
会显示成方框；想让它们也显示出来，把一个完整的中日文字体复制到 SD 卡：

    /3ds/moonlight/kiripanel/font.ttf     （也可以是 font.ttc 或 font.otf）

推荐 TrueType 格式（.ttf / .ttc）的思源黑体、Noto Sans CJK 等。字体按需读取，不占内存。


七、卸载
--------
在 KiriPanel 里选中游戏，点「卸载插件」。只删除插件自己放进去的
version.dll（或 mpr.dll）和 kiripanel 文件夹，游戏自己的文件一个都不会动。
KiriPanel 本身是一个文件，删掉即可；它的设置在 %LOCALAPPDATA%\kiripanel。


八、出问题时
------------
  3DS 下屏一直显示「正在连接 <地址>」
      → 电脑上的 KiriPanel 没开，或者防火墙拦了 8787（Windows 安全中心 → 防火墙 →
        允许应用通过防火墙 → 勾选 KiriPanel 的「专用」）。3DS 和电脑要在同一个网络。
  3DS 下屏显示「游戏未运行」
      → 游戏还没启动，或这个游戏没装插件（KiriPanel 里看「已安装」）。
  显示「这款游戏暂不支持台词面板」
      → 插件在游戏里运行了，但没有适配器认识它：属于「需要适配器」那一档。
  显示「版本不匹配」
      → KiriPanel 和 3DS 端不是同一个版本，或游戏里的插件是旧的：在 KiriPanel 里点「更新插件」。
  KiriPanel 显示「端口 8787 被占用」
      → 已经开着另一个 KiriPanel 或旧的 relay.py，关掉它再开。
  游戏里的对话框没有隐藏
      → 看 KiriPanel 里「电脑上的对话框」的设置；3DS 在台词面板（DIALOG）模式时才会隐藏，
        3DS 断开 4 秒内会自动恢复显示。

插件的日志在 %LOCALAPPDATA%\kiripanel\kiripanel.log，求助时请附上它，
以及在游戏运行时用「导出诊断报告」得到的文件。
